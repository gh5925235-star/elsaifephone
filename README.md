# السيف للهواتف | ALSAIF PHONES

Luxury e-commerce and device-installment platform tailored for the Kingdom of Bahrain.

## Stack

- TanStack Start v1 + React 19 + TypeScript
- Tailwind CSS v4
- Vite

## Scripts

- `bun dev` — start development server
- `bun build` — production build
- `bun preview` — preview production build

## Notes

- The storefront is fully RTL Arabic with Bahraini-Dinar pricing.
- Admin credentials are configured in the admin settings.
